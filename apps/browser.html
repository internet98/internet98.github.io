About Internet Expedition

Internet Expedition is a retro-styled portal for discovering surviving websites and historical web archives.

Search engines and web archives have different indexes. A search cannot guarantee that a site still exists or that an archived snapshot is complete.

This version uses external search services for discovery and the Wayback Machine for archived website snapshots. It does not claim to own or index the entire old internet.
